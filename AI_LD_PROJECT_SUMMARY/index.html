AI-Powered Learning & Development Assistant

A Tata Steel internship project focused on transforming Learning & Development using Artificial Intelligence, Agentic AI, Retrieval-Augmented Generation (RAG), and Personalized Learning Recommendations.

Project Overview

The objective of this project is to solve critical Learning & Development challenges within large industrial organizations by leveraging Generative AI. The assistant helps employees quickly access SOPs, training manuals, safety documents, and personalized learning recommendations while preserving organizational knowledge.

Key Solution Components

AI Learning Assistant

Provides intelligent responses to employee training queries, safety procedures, and SOP-based questions.

Interactive Dashboard

Built using Streamlit to provide an intuitive interface for workforce learning and engagement.

Personalized Training

Recommends training modules and learning pathways based on employee skills and requirements.

System Architecture



User Query → Document Retrieval → RAG Pipeline → AI Model → Context-Aware Response
